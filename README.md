# Kasel Digital Solutions Ltd

Official company website for **KASEL DIGITAL SOLUTIONS LTD**.

The responsive single-page website showcases the company’s core services:

- Web and mobile development
- UI/UX and brand design
- Video and digital content
- Digital transformation

## Technology

- React 19
- TypeScript
- Vinext / Vite
- Tailwind CSS

## Local setup

You need Node.js 22.13 or newer.

```bash
npm install
npm run dev
```

Open the local address displayed in the terminal.

## Production build

```bash
npm run build
```

## Main files

- `app/page.tsx` – webpage content and structure
- `app/globals.css` – styling and responsive layouts
- `app/layout.tsx` – page metadata and shared layout
- `public/kasel-orb.png` – hero artwork

## Before publishing

Confirm that `hello@kaseldigitalsolutions.com` is the correct business email. It appears in the contact section and project enquiry links.
